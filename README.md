## 📖 The Story

Started this as my "I'm gonna build an amazing portfolio" project. You know, the one every developer promises themselves.

The plan was _ambitious_:

```
✓ Cool intro page          (done! finally something works)
○ Project showcase         (soon™)
○ Work experience timeline (it's on the roadmap... somewhere)
○ Blog section             (lol)
```

Plot twist: I got hired before finishing any of that. So here we are - a fancy profile card pretending to be a portfolio.

Will I finish it? Probably. When? Good question.

---

## 💡 Fun Fact

This entire website runs on **an old laptop sitting in my room**. Yes, literally in my room. Right now. Probably overheating.

No AWS, no Vercel, no subscription fees. Just vibes and a laptop that refuses to retire. Only expense? A cheap domain.

Self-hosted gang rise up. 🏠
